# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

Only the latest published release receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately by
emailing **mattmezza@gmail.com** instead of opening a public issue.

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact

You can expect an acknowledgment within 48 hours, and we'll work with you
to understand the issue and coordinate a fix and disclosure.

We do not currently operate a bug bounty program, but we'll acknowledge
your contribution in the release notes if you choose to be credited.
